# Tincons Pro — Bản phát hành

Kho này chỉ chứa tệp cài đặt (trong mục **Releases**) và `latest.json` dùng cho tính năng tự động cập nhật. Không chứa mã nguồn.

- Windows: `TinconsPro-Setup-vX.Y.Z.exe` (cài đặt) hoặc `TinconsPro-vX.Y.Z.exe`
- Android: `TinconsPro-vX.Y.Z.apk` — cần khóa kích hoạt do Chủ sở hữu cấp.

Tải bản mới nhất: https://github.com/phankimtuyen/tincons-pro-releases/releases/latest
